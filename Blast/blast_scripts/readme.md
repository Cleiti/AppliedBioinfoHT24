SLURM batch scripts for Blast, for report section 2.2.1. 
clavipes_blast.sh does the entire reciprocal blast for the clavipes transcriptome. 
clavata_blast.sh does the forward blast for the three clavata transcriptomes.
rev_clavata_blast.sh does the reverse blast step of the reciprocal blast for the three clavata transcriptomes.
