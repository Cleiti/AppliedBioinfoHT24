Contains scripts for all work done for the tissue expression analysis. 

The OG_expression_converter are preprocessing scripts used in section 2.2.1 of the report that convert the bulkRNA expression files to TPM normalized expression files with orthogroups.
The expression_pearson file contains code for sections 3.3.1 and 3.3.3.
The Variable_featura_ranking folder contains code for section 3.3.2
