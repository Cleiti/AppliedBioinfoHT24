# AppliedBioinfoHT24

This repository contains code used for data analysis in the 1000 spider project, carried out as a part of the course Applied Bioinformatics at Uppsala University during the 2024 autumn semester. The project investigates expression patterns of orthologous genes using tissue-specific bulk expression data from spider species *Larinioides sclopetarius* and *Trichonephila clavata*, and single-cell RNA sequencing data from *Trichonephila clavata* and *Trichonephila clavipes*. 

The code contains local paths and references to data files that we can't publish. As such, the main purpose of this repository is not reproducibility, but method transparency.
